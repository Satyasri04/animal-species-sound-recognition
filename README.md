# 🐾 Animal Species Sound Recognition System

An AI-based system that classifies animal species from audio recordings using deep learning.  
The project uses **YAMNet (transfer learning)** for feature extraction and a **Deep Neural Network (DCNN)** for multi-class classification, with a **Flask web interface** for real-time predictions.

---

## 🚀 Features

- 🎧 Upload `.wav` audio files for prediction  
- 🧠 Deep learning-based classification  
- 🔍 Feature extraction using **YAMNet embeddings**  
- ⚡ Fast and real-time predictions  
- 🌐 User-friendly Flask web interface  
- 📊 Displays prediction confidence  

---

## 🛠️ Technologies Used

- Python  
- TensorFlow / Keras  
- TensorFlow Hub (YAMNet)  
- Flask  
- NumPy, Librosa  
- ESC-50 Dataset
